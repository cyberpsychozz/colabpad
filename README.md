# ColabPad

**Рисуй вместе. Без отмены.**

ColabPad — онлайн-холст для совместного рисования в браузере, где **нет кнопки Undo и ластика**. Каждый штрих остаётся навсегда, как на бумаге. Создаёшь холст одной кнопкой, получаешь ссылку, кидаешь друзьям — и все рисуют одновременно. Без регистрации.

Целевой публичный адрес из ТЗ: **https://collabpad.ru** (для `colabpad.ru` подготовлено перенаправление). В рамках локальной реализации сервер в интернете не публиковался. После локального запуска приложение открывается по адресу **http://127.0.0.1:8000/**.

---

## Что входит в MVP

1. **Холст реального времени без отмены.** Кисть с выбором цвета и толщины, рисование мышью, пальцем или стилусом. Штрихи сразу видны всем участникам. Отменить или стереть штрих нельзя.
2. **Холст по ссылке.** Кнопка «Создать холст» выдаёт ссылку вида `collabpad.ru/c/k3x9aQ7mPz`. Все, у кого есть ссылка, рисуют вместе. По той же ссылке холст открывается в любой момент.
3. **Таймлапс и PNG.** Проигрывание истории холста штрих за штрихом и скачивание картинки.

Плюс две «кнопки-заглушки» (fake-door): **Pro** и **«Купить штрих на большом холсте»**. Они ничего не продают, а только считают клики, чтобы проверить интерес к монетизации.

**Чего в MVP нет и не будет:** аккаунтов, разных типов доступа к холсту, ссылок только для просмотра, модерации, ластика, слоёв, режима с отменой (исключён окончательно), реальной оплаты, мобильного приложения.

Полное ТЗ с обоснованиями: [`docs/ColabPad_Архитектура_и_ТЗ.docx`](docs/ColabPad_Архитектура_и_ТЗ.docx).
Инструкции для ИИ-агента (на английском, самые свежие и подробные): [`AGENTS.md`](AGENTS.md).

Пользовательская инструкция по предоставленному шаблону, с пошаговыми скриншотами:

## Как это устроено

```
Браузер (Vite + чистый JS + Canvas)
   │  REST: создать / загрузить холст
   │  WebSocket (Socket.IO): штрихи и «кто онлайн»
   ▼
Nginx (на сервере) — HTTPS, редиректы доменов, проксирование WebSocket
   ▼
FastAPI + python-socketio, Uvicorn, 1 процесс (Docker или systemd)
   ▼
SQLite  (/var/lib/colabpad/colabpad.db)
```

Как идёт штрих:

1. Пока ты ведёшь линию, она сразу рисуется у тебя на экране.
2. Когда отпускаешь перо, клиент упрощает линию и отправляет её на сервер.
3. Сервер проверяет данные, присваивает штриху порядковый номер (`seq`), сохраняет его в базу и рассылает остальным.
4. Если связь пропала, штрихи копятся в очереди и досылаются после переподключения. Дубли сервер отсекает сам.

### Три правила, которые нельзя нарушать

- **Штрихи неизменяемы.** В коде нет операций изменения и удаления штрихов, а в базе стоят триггеры, которые их запрещают. Никаких «очистить холст», «удалить штрих» или «режима с отменой».
- **Ровно один процесс Uvicorn** (`--workers 1`). Список «кто онлайн» и порядок штрихов держатся в памяти одного процесса.
- **Никаких персональных данных.** IP, email и User-Agent не храним. Имя необязательное, до 30 символов.

## Запуск локально

Быстрый запуск через Docker:

~~~bash
docker compose up --build -d --wait
~~~

Открой http://127.0.0.1:8000. Интерфейс собирается внутри образа, база хранится
в отдельном томе. Остановка — docker compose down; том с рисунками сохраняется.
Настройки, обновление, резервные копии и перенос существующей базы описаны
в [docs/DOCKER.md](docs/DOCKER.md).

### Запуск без Docker

Нужны Python 3.12 и Node.js 20+.

```bash
# сервер
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:asgi --reload --port 8000

# фронтенд (в другом терминале)
cd web
npm install
npm run dev
```

Открой http://localhost:5173. Vite сам проксирует `/api` и `/socket.io` на сервер (порт 8000).
Документация API: http://localhost:8000/docs.

Проверить совместное рисование проще всего в двух вкладках браузера (или во вкладке и на телефоне в той же сети).

**Тесты:** `pytest -q`

**Сборка фронтенда для прода:** `cd web && npm run build` (результат попадает в `app/static/`, его отдаёт FastAPI).

## Настройки

Все параметры задаются переменными окружения (локально — файл `.env`, на сервере — `/etc/colabpad/colabpad.env`). Пример — в `deploy/colabpad.env.example`.

| Переменная | По умолчанию | Что это |
|---|---|---|
| `DB_PATH` | `./data/colabpad.db` | Путь к базе. На сервере: `/var/lib/colabpad/colabpad.db` |
| `CORS_ORIGINS` | `http://localhost:5173` | На сервере: `https://collabpad.ru` |
| `CANVAS_WIDTH` × `CANVAS_HEIGHT` | 1600 × 1000 | Размер холста |
| `MAX_STROKES_PER_CANVAS` | 5000 | После этого холст становится только для просмотра |
| `MAX_CLIENTS_PER_CANVAS` | 20 | Одновременных участников на холсте |
| `STROKE_RATE_LIMIT` | 30/10 | Не больше 30 штрихов за 10 секунд с одного подключения |
| `BRUSH_WIDTH_MIN` / `MAX` | 1 / 40 | Толщина кисти |
| `PALETTE` | 8 цветов | Палитра по умолчанию |

Полный список — в `AGENTS.md`, раздел 8.

## Деплой (вариант по умолчанию)

Для Docker используется compose.yaml; внешний Nginx и сертификаты настраиваются
по [инструкции Docker](docs/DOCKER.md). Ниже описан альтернативный вариант:
**VPS, Nginx в системе, приложение как сервис systemd**.

- Основной домен — **collabpad.ru**.
- **colabpad.ru** (с одной «l», «опечатка»), а также `www.` у обоих доменов → постоянный редирект (301) на `https://collabpad.ru`.
- Бюджет: хостинг 250 ₽/мес, домен 120 ₽.

### Первый запуск на сервере

1. **DNS.** A-записи для `collabpad.ru`, `www.collabpad.ru`, `colabpad.ru`, `www.colabpad.ru` → IP сервера.
2. **Пакеты.** `sudo apt install python3.12 python3.12-venv nginx certbot sqlite3 git` + Node.js 20 (для сборки фронтенда).
3. **Пользователь и папки.**
   ```bash
   sudo useradd --system --create-home --home-dir /opt/colabpad colabpad
   sudo mkdir -p /var/lib/colabpad/backups /etc/colabpad
   sudo chown -R colabpad:colabpad /var/lib/colabpad
   ```
4. **Код.** Склонировать репозиторий в `/opt/colabpad`, создать venv, `pip install -r requirements.txt`, собрать фронтенд.
5. **Настройки.** Скопировать `deploy/colabpad.env.example` в `/etc/colabpad/colabpad.env`, поправить `DB_PATH` и `CORS_ORIGINS`.
6. **Сервис.** `deploy/systemd/colabpad.service` → `/etc/systemd/system/`, затем `sudo systemctl enable --now colabpad`.
7. **Nginx и сертификат.** Сначала включить в Nginx только блок для порта 80 и получить один сертификат на все четыре имени:
   ```bash
   sudo mkdir -p /var/www/certbot
   sudo certbot certonly --webroot -w /var/www/certbot \
     -d collabpad.ru -d www.collabpad.ru -d colabpad.ru -d www.colabpad.ru
   ```
   Потом подключить полный `deploy/nginx/colabpad.conf`, проверить и перезагрузить: `sudo nginx -t && sudo systemctl reload nginx`.
8. **Проверка.** `https://collabpad.ru/api/health` отвечает `{"ok":true}`, а `http://colabpad.ru` перекидывает на `https://collabpad.ru`.

Готовые конфиги Nginx и systemd — в `AGENTS.md`, раздел 10 (и в папке `deploy/`).

### Обновление

```bash
sudo /opt/colabpad/deploy/update.sh
```

Скрипт подтягивает код, ставит зависимости, собирает фронтенд и перезапускает сервис. Пользователи переподключатся сами, и ничего не потеряется.

### Резервные копии

Раз в сутки по cron: `sqlite3 ... ".backup ..."` в `/var/lib/colabpad/backups/`, храним последние 14 копий. Файл базы нельзя копировать обычным `cp`, пока приложение работает.

## План работ (≈ 50 часов, 7 дней)

| День | Задачи |
|---|---|
| 1 | Каркас проекта и первый деплой на домены (T1), база данных (T2), начало кисти (T4) |
| 2 | Кисть (T4), комнаты и «кто онлайн» (T5) |
| 3 | REST API (T3), приём штрихов на сервере (T6) |
| 4 | Синхронизация на клиенте и переподключение (T7), открытие холста по ссылке (T8) |
| 5 | Таймлапс (T9), PNG (T10) |
| 6 | Главная и все состояния интерфейса (T11), кнопки-заглушки (T12), финальный деплой и бэкапы (T13) |
| 7 | Тест с 5–10 друзьями, исправление багов (T14) |

Если не успеваем, в первую очередь упрощаем таймлапс (только play/pause). Надёжность синхронизации (T6, T7) не режем.

Подробно по каждой задаче, с критериями готовности, — в `AGENTS.md`, раздел 11.

## Открытый вопрос: платный штрих

Обсуждаем монетизацию по модели **The Million Dollar Homepage** (2005, страница 1000×1000 пикселей по $1 за пиксель): большой публичный холст, где каждый штрих платный и остаётся навсегда. Это **не делаем в MVP**, только считаем клики по кнопке «Купить штрих на большом холсте». Вопросы для обсуждения (цена, модерация, связь с подпиской Pro, юридическая сторона) — в ТЗ, раздел 5.4.
