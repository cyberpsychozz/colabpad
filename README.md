# CollabPad · Живой холст

**Нарисуй — и оно оживёт.**

CollabPad — один большой общий мир в браузере, где рисунки оживают. Рисуешь (без отмены:
каждый штрих остаётся навсегда), нажимаешь ✨, обводишь рисунок и жмёшь **ОЖИВИ** /
**ALIVE**. Нейросеть понимает, что это (корова, волк, озеро, бомба, машина…), сервер
собирает из твоих же линий анимированный спрайт, и объект начинает жить: ест, пьёт,
охотится, размножается, горит, взрывается или ездит с пульта. Всё это видят все, кто
смотрит на тот же кусок мира. Интерфейс на русском и английском.

Адрес: **https://collabpad.ru** (`colabpad.ru` перенаправляется на него).

- Бесплатно: общий мир, реклама РСЯ по бокам, 10 оживлений в день без входа и 20 со входом.
- «Плюс» (299 ₽/мес): без рекламы, до 5 приватных миров с доступом по ссылке и ролям,
  50 оживлений в день. Платит только хозяин мира.

## Как это устроено

```
Браузер (Vite + чистый JS + Canvas 2D, RU/EN)
   │  REST: мир, куски мира, оживление, вход, оплата
   │  Socket.IO: штрихи, подписка на куски мира, дельты мира, управление
   ▼
Nginx — HTTPS, редиректы доменов, WebSocket
   ▼
FastAPI + python-socketio, Uvicorn, ровно 1 worker
   ├── очередь оживлений: растр (skia-python) → нейросеть (OpenRouter) → риг и спрайт (Pillow, numpy)
   └── процесс симуляции мира (10 тиков в секунду, numpy), перезапускается сам
   ▼
SQLite (DATA_DIR/collabpad.db) + спрайты (DATA_DIR/sprites/)
```

Мир разбит на куски 1024×1024 px; клиент подписан не больше чем на 12 кусков вокруг
экрана. Сервер — единственный источник правды: клиент только рисует и сглаживает движение.

### Правила, которые нельзя нарушать

- **Штрихи неизменяемы.** Строки `stroke` никогда не меняются и не удаляются; судьба штриха
  (оживлён, уничтожен взрывом, окаменел) пишется в отдельную таблицу `stroke_fate`, тоже
  только на добавление. Это обеспечивают триггеры в базе.
- **Ровно один процесс Uvicorn** (`--workers 1`) и один процесс симуляции.
- **Без живых ключей.** ЮKassa только в тестовом режиме, ключи — только из переменных
  окружения, у нейросети дневной лимит расходов.

## Запуск локально

```bash
./start.sh
```

Открой http://127.0.0.1:8000/w. Подготовка окружения с нуля и запуск через Docker —
в [`LOCAL.md`](LOCAL.md). Без ключа нейросети оживление работает через ручной выбор типа;
без SMTP ссылки для входа пишутся в лог сервера.

Тесты:

```bash
env -u PYTHONPATH .venv/bin/python -m pytest -q
```

```bash
cd web && npm test
```

После изменений в `web/` пересобери фронтенд: `cd web && npm run build` (результат
попадает в `app/static/`).

## Настройки

Переменные окружения (в `.env`, пример — `.env.example`; на сервере `/opt/collabpad/.env`): `DATA_DIR`, `PUBLIC_URL`, `SMTP_*`,
`VLM_API_KEY`, `VLM_PROXY_URL` (прокси только для нейросети), `YOOKASSA_*`, `ADS_BLOCK_*`, `CORS_ORIGINS` и параметры кисти.

Игровые настройки и флаги — в `config/*.yaml`: типы объектов (`archetypes.yaml`), баланс,
лимиты и квоты, модели нейросети, цены, флаги (`flags.yaml`: реклама, автопродление,
нейросеть, догонялка спящих кусков мира).

## Структура

```
app/        сервер: main.py, config.py, db.py, schema.sql, retention.py
  realtime/ Socket.IO: комнаты кусков мира, штрихи, управление
  repo/     SQL по семействам таблиц
  alive/    оживление: выбор штрихов, растр, нейросеть, риг, очередь
  sim/      симуляция мира: процесс, мост с основным процессом, ECS, системы, типы
  auth/ billing/ i18n/
web/src/    клиент: камера, куски мира, рисование, сокет, отрисовка, интерфейс, i18n
config/     YAML-настройки и флаги
prompts/    промпт классификации
scripts/    loadtest.py — нагрузочный тест
deploy/     Nginx хоста, бэкап, update.sh (Docker Compose); установка — docs/agent/deploy.md
tests/      pytest
```
