## Границы передачи

Согласно запросу работа локальная. DNS, VPS, системные сервисы и сертификаты на реальном сервере не изменялись. Тест с друзьями, Safari/iOS, Firefox, Edge и физическим стилусом не проводился. Адаптивные стили подготовлены; проверка на реальных мобильных устройствах остаётся открытой.

В локальной базе оставлены тестовые холсты. Они находятся в исключённой из Git папке data/. Скриншот рабочего холста — previews/canvas.png.

## Решения по расхождениям

В DOCX лимит штрихов проверяется раньше clientId; в AGENTS.md — наоборот. Реализован порядок AGENTS.md, чтобы повторная отправка на полном холсте оставалась идемпотентной. Сообщение о медленной загрузке тоже взято из AGENTS.md.

Полный набор клиентских настроек передаётся при загрузке холста согласно разделу 8 AGENTS.md. Кроме сокращённого перечня раздела 6.2 ответ включает maxPointsPerStroke, maxPayloadBytes, simplifyEpsilon и nameMaxLen. Существующие поля и события сохранены.

Для восстановления после гонки событий клиент хранит максимальный seq и непрерывный подтверждённый префикс. При пробеле догрузка начинается с префикса, а не с более позднего увиденного события.

## Docker по дополнительному запросу владельца

9 ноября 2026 года добавлены Dockerfile, compose.yaml и .dockerignore.
Образ собирается из официальных Node.js 22 и Python 3.12. Runtime запускает
один Uvicorn worker от UID/GID 10001. В Compose опубликован только локальный порт,
корень контейнера доступен только для чтения, SQLite находится в именованном томе.

Проверка выполнена в отдельном проекте colabpad-docker-qa на порту 18080:
